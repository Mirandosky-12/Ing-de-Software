# Portal Único Municipal de Permisos

![Imagen](https://img.shields.io/badge/Lenguaje-JavaScript-crimson)

### Esta solución digitaliza la solicitud, revisión, aprobación y auditoría de permisos municipales para reducir el tiempo de meses a días y conservar un historial verificable.
